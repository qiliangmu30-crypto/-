# Nonviolent Communication（NVC）

## OFNR 结构

1. **Observation / 观察**：描述可观察事件，不把评价伪装成事实。
2. **Feeling / 感受**：表达自己的体验，避免“我觉得你不尊重我”式的判断句。
3. **Need / 需要**：说明与感受相关的价值或需要，不把特定策略写成需要。
4. **Request / 请求**：提出具体、当下、可执行且可拒绝的请求。

例：“我们约定八点通话，九点还没收到消息（观察）。我担心也失望（感受），因为我需要可预测和被考虑（需要）。下次若会晚，你愿意提前发一句吗（请求）？”

## 倾听侧

以好奇猜测对方的感受与需要，并允许其修正；[[Concepts/Validation|确认体验]]不等于同意其所有解释。

## 局限与风险

NVC 不应成为语言警察或包装要求的技巧。高唤醒时先调节；有暴力与强迫控制时，安全、证据和边界优先于共情式对话。
