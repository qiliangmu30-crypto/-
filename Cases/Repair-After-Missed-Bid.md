# 合成案例：错过连接请求后的修复

## 背景与事实

C 回家说“今天发生一件很糟的事”，D 正在赶工作，只说“等会儿”。两小时后 C 已睡下。第二天 C 说“昨晚我觉得自己不重要”；D 先回答“我不是那个意思”，随后停下并重新回应。

## 行为、情绪与需要

C 的原始连接请求被错过，可能感到孤单、失望，需要回应。D 可能专注和压力高，需要完成任务，并没有意识到请求的紧迫程度。

## 多理论分析

- Gottman：这是错过的连接请求；关键是后续 [[Concepts/Repair-Attempt|修复尝试]]。
- EFT：C 的“我不重要”可能是连接威胁；D 的解释可能先保护自己。
- NVC：C 已表达影响；D 可先确认，再说明意图和提出未来请求。
- 认知：影响与意图不同，“没回应”既不证明不爱，也不使伤害感无效。

## 修复对话示例

D：“我听到的是，你昨晚需要我停一下，而我的‘等会儿’没有说明多久，让你一个人扛着。这个影响我愿意负责。下次我能先问是紧急倾听五分钟，还是约一个明确时间吗？”

C 可选择接受、修正或要求不同安排。修复是否有效要看之后行为，不只看句式。
