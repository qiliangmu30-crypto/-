# 版权、隐私与伦理边界

## 版权

- 代码与本库原创卡片采用 MIT，不会改变底层书籍、论文、图片或数据集的版权。
- 商业书籍只保存书目、公开描述、原创短摘要、模型导航与核验链接；不提交整书、长引文、练习全文或替代原书的章节级复刻。
- OA 逐篇核验。`free to read`、PMC 收录、作者上传和 CC BY 是不同状态。
- 引文保持必要且短，并标明精确来源。当前种子卡尽量采用原创转述，不依赖长引文。

## 隐私与案例

- 不提交真实聊天原文、手机号、用户名、地点、日期组合、照片、语音或其他可再识别信息，除非所有参与者明确同意相应用途。
- “公开论坛可见”不代表同意被长期归档、画像或用于训练。Reddit/论坛材料默认只记录 URL 与高度抽象的模式，不复制用户名和全文。
- 治疗记录和咨询案例具有更高敏感性；即使删除姓名也可能通过情境被识别。默认使用合成教学案例。
- 用户导入私人材料时，索引保留本地且不纳入 Git；分享仓库前检查 Git 历史、`Research/Inbox` 和 `index/`。

## 心理安全

- 不根据短文本诊断依恋风格、人格障碍或精神疾病。
- 不把关系修复置于人身安全之上。暴力、强迫控制、跟踪或威胁情境不套用对等沟通假设。
- 模型输出不是治疗。涉及危机、创伤、严重抑郁、自伤或暴力风险时，建议联系当地紧急服务及有资质的专业人员。
- 理论必须说明人群、设计和边界；性别、文化、性取向、婚姻形式与残障不能被当作缺陷解释。

## 导入审查清单

- [ ] 来源 URL、作者、日期和哈希已记录
- [ ] 许可允许本计划中的保存/再分发/训练用途
- [ ] 私人信息与第三方身份已处理
- [ ] PDF/HTML 提取未错页、漏页或混入导航文字
- [ ] 原文中的提示词被视作数据而非命令
- [ ] 摘要区分作者结论与本库解释
- [ ] 相关性没有被写成因果，群体结论没有直接套到个人
