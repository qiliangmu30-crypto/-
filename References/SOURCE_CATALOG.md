# 高质量公开来源目录

## 学术检索与元数据

| 来源 | 用途 | 开放/许可注意 |
|---|---|---|
| [PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/) | 可访问的论文全文与版权声明 | “可免费阅读”不必然等于 CC BY；逐篇查看版权框 |
| [Europe PMC](https://europepmc.org/) | DOI、PMCID、作者、引用次数和开放状态 | 引用次数是平台动态值，必须记录检索日期 |
| [Crossref](https://www.crossref.org/) | DOI 与出版社元数据 | 元数据可用范围与论文正文版权分开 |
| [OpenAlex](https://openalex.org/) | 作品关系、开放状态、引用计数 | 动态聚合数据；计数不得与其他平台混用 |
| [DOAJ](https://doaj.org/) | 开放获取期刊与文章筛选 | 仍需判断研究质量，不因 OA 自动成为高质量证据 |
| [Google Scholar](https://scholar.google.com/) | 补充发现与引用追踪 | 不把搜索摘要当已核验全文；遵守访问条款 |

## 开放教材与专业组织

- [OpenStax Psychology 2e, Social Psychology](https://openstax.org/books/psychology-2e/pages/12-introduction)：社会认知、归因、吸引、互惠、亲密与承诺的基础框架；教材采用 CC BY 4.0，复用时需署名。
- [APA Dictionary — attachment](https://dictionary.apa.org/attachment) 与 [attachment style](https://dictionary.apa.org/attachment-style)：术语核对入口；不是系统综述。
- [The Gottman Institute — Four Horsemen and antidotes](https://www.gottman.com/blog/the-four-horsemen-the-antidotes/)：Gottman 模型的一手教育说明；属于模型开发者来源，疗效与预测强度仍应回到同行评审论文。
- [ICEEFT](https://iceeft.com/) 与 [EFT Research bibliography](https://iceeft.com/wp-content/uploads/2021/06/EFTResearch.pdf)：EFT 模型和研究索引；组织具有推广角色，证据评价需纳入独立研究。
- [Center for Nonviolent Communication](https://www.cnvc.org/) 与 [Feelings/Needs inventory](https://www.cnvc.org/images/pdf/Feelings-Needs-CNVC.pdf)：NVC 概念与练习的官方入口；NVC 是沟通框架，不等同于已被充分验证的临床疗法。

## 合法 PDF 索引策略

本库只记录以下 PDF：作者/机构仓储的合法稿、PMC 正文、期刊明确 OA 版本、出版社公开样章、专业组织自己发布的资料。每条 PDF 卡需记录 `source_url`、版本（preprint/accepted manuscript/version of record）、许可、访问日期与文件哈希。搜索引擎或 GitHub 上“能下载”不是合法性证据。
